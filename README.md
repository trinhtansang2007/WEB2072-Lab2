# WEB2072 - Lab 2

Reactive State, `ref()`, `reactive()`, Data Binding trong Vue.js.

## Chạy project

```sh
npm install
npm run dev
```

## Nội dung

- `src/Labs/Lab-2/Bai1.vue` - Quản lý giỏ hàng với `ref()`
- `src/Labs/Lab-2/Bai2.vue` - Quản lý người dùng với `reactive()`
- `src/Labs/Lab-2/Bai3.vue` - One-way và Two-way Binding
- `src/Labs/Lab-2/Bai4.vue` - Class và Style Binding
